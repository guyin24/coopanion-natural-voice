自然语音插件首次公开发布，适用于 Coopanion / Cortico World API 6，Windows。

- 适配 8 个语音平台及自定义兼容服务，自动获取模型与音色，提供试听和停止。
- 阿里 WebSocket 连续推流、提前握手、首句预合成，常驻播放器支持打断恢复。
- 默认跟随回复已有表情；可选 `tones` 简短标注，不重复生成正文。
- 包含队列、缓存、气泡同步自检和失败降级修复。

下载 **Coopanion-Natural-Voice-0.6.0.zip**，解压后在 Coopanion 的 World 扩展中通过“本机目录”安装，选择含 `package.json` 的文件夹。保留该目录，配置和 Key 在宿主中填写。`SHA256SUMS.txt` 用于校验；`.tgz` 为 npm 格式归档，此次未发布到 npm registry。

本机 268 项测试通过，实际阿里云合成、Windows 连续播放、安装版对话及停止恢复已验证。CI 无音频设备时跳过单个真实设备用例，运行协议与播放器模拟测试。其他平台的真实凭据、干净系统和多设备矩阵未覆盖。完整范围见仓库 `docs/validation.md`。

需要自备 TTS 凭据，云端使用可能收费。声音为 AI 合成。语气效果由模型和音色决定；不保证逐字/口型同步。
