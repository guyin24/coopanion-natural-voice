## 自然语音 0.7.0

- **市场版**保留多平台自动朗读、试听、情感表达和阿里推流。通过 World API 读取桌宠的新发言，气泡由 Coopanion 直接显示。使用市场版 ZIP 或 npm 包。
- **完整版**另外提供实验性气泡同步。该功能依赖宿主内部连接接口，最多延后气泡 1800 毫秒。通过完整版 ZIP 手动安装。
- 以 Coopanion 0.2.19 随附的 Cortico 0.2.14 为验证基线，并在 CI 中检查最新正式版的插件契约。

两版使用同一个插件 ID，同一实例只装一版。市场展示须等待市场维护方复核。

解压对应 ZIP 后，在 Coopanion 的「World 扩展 → 手动安装 → 本机目录」选择含 `package.json` 的文件夹。[配置与升级说明](https://github.com/guyin24/coopanion-natural-voice/blob/v0.7.0/INSTRUCTIONS.md)
