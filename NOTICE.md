# Project and data sources

Natural Voice is an independently maintained third-party plugin for [Coopanion](https://github.com/Pal-AI-Lab/Coopanion), built against the public [Cortico](https://github.com/Pal-AI-Lab/Cortico) World API 6 interface.

This repository distributes the plugin, not the host applications or their source trees. The plugin has its own MIT license. Refer to the upstream repositories for the licenses governing those projects.

Voice/model identifiers, names and short catalog descriptions are derived from provider documentation. They identify external services and do not include voice recordings or model weights, grant service access, or replace provider terms. Catalog sources and verification dates are recorded in `docs/catalog-aliyun.md`, `docs/catalog-remote.md` and the source JSON metadata. Protocol references are in `INSTRUCTIONS.md` and the provider documents.

Microsoft Windows audio functions are called through system libraries; no Windows library, SDK, NAudio binary or third-party speech model is redistributed.
